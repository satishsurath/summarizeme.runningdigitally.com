## Summary

Phase 2 of the UI/UX improvement series: redesigned navigation with notification dropdown.

## Changes

### Navigation Redesign
- Replaced **Home** nav link with **Channels** (more descriptive)
- Replaced **Check Status** nav link with **notification bell dropdown**
- Kept **Admin** nav link
- Added **Status** link in mobile menu (link to /status page)
- Added dark mode toggle in mobile menu

### Notification Dropdown (static/js/notifications.js)
- Auto-polls /api/active-tasks every 5 seconds
- Shows badge count for active tasks
- Status dots: green (completed), yellow (in_progress), red (failed)
- Progress bars for in-progress tasks
- XSS-safe HTML escaping
- Click task row navigates to /status
- Closes on outside click or Escape key

### API Endpoint (blueprints/api.py)
- New GET /api/active-tasks endpoint
- Returns active (pending/in_progress) tasks from both download and summarize task dicts

### CSS (static/css/components.css)
- Added .icon-btn class for consistent button styling
- Added notification dropdown classes

### Accessibility
- Skip navigation link
- ARIA labels on all interactive elements
- aria-expanded / aria-controls on dropdown
- aria-live region for screen reader announcements
- Escape key closes dropdowns

### Bug Fixes
- Fixed pyright type errors in api.py (SQLAlchemy column type false positive)
