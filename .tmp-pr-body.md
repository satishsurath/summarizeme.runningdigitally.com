## Summary

Phase 3 of the UI/UX improvement series: centralized icon system replacing all inline SVGs.

## Changes

### Icon Library (static/js/icons.js)
- New centralized icon library with `IconLibrary.render(name, size, extraAttrs)`
- Supports 15+ icons: bell, sun, moon, menu, x, check, warning, info, edit, trash, refresh, chat, chevronDown, folder, back, document
- Size variants: sm (w-4 h-4), md (w-5 h-5), lg (w-6 h-6), xl (w-8 h-8)
- `renderCustom()` for dynamic SVG paths

### Template Macro (templates/macros.html)
- New `render_icon(name, size, extra_class, extra_id, extra_style)` Jinja macro
- Mirrors the JS library for server-side rendering

### CSS Fix (static/css/icons.css)
- Replaced `@apply` directives with explicit CSS (CDN compatibility — same fix as Phase 1 for components.css)

### Template Replacements
- **layout.html**: bell, sun, moon, menu icons → macro calls
- **index.html**: edit, trash, refresh, chat icons → macro calls
- **channel_chat.html**: chat icon → macro call (YouTube sprite preserved)
- **summary_v2.html**: 12 icons (document, chevronDown) → macro calls
- **transcript_v2.html**: 4 icons (document, chevronDown) → macro calls
- **video_chat.html**: chevronDown icon → macro call

### JS File Replacements
- **index.js**: edit, trash, refresh, chat icons → `IconLibrary.render()`
- **toast.js**: x, check, warning, info icons → `IconLibrary.render()`
- **status.js**: error icon → `IconLibrary.renderCustom()`

### Accessibility
- Spinner SVGs preserved (CSS animated, not icons)
- YouTube sprite sheet preserved (used with `<use>`)
